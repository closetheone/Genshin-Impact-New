# Genshin-Impact-New

一个用于查阅原神文本、探索有依据的人物关系，并让 AI 基于资料创作剧情脚本的项目。

## 核心体验

```text
检索原文 → 阅读上下文 → 核对出处
                         ↓
                   人物关系图 → 关系证据
                         ↓
                      素材包 → Skill 剧情创作
```

首发计划为简体中文响应式网站。AI 创作优先通过外部助手中的 Skill 完成，站内 AI 工作台属于后续范围。

## 当前状态

目前处于需求整理与数据可行性准备阶段：只有项目文档，尚无可运行的网站、数据库、采集器、关系图页面或已导入的原神全文数据。因此本仓库暂不提供应用启动命令。

本机已有 `genshin-story-writer` 工作流文件，但尚未纳入本仓库、打包或连接真实检索工具。克隆仓库不能直接获得可用的创作系统；相关交付列入 T08。

## 下一步
