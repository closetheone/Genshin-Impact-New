# Genshin-Impact-New

一个用于查阅原神文本、探索有依据的人物关系，并让 AI 基于资料创作剧情脚本的项目。

## 核心体验

```text
检索原文 → 阅读上下文 → 核对出处
                         ↓
                   人物关系图 → 关系证据
                         ↓
                      素材包 → Skill 剧情创作
```

首发计划为简体中文响应式网站。AI 创作优先通过外部助手中的 Skill 完成，站内 AI 工作台属于后续范围。

## 当前状态

目前已执行首次数据结构试验：保存了五页候选来源的技术观察，以及 32 段原创文本、4 个人物、7 条关系记录的合成样本，并提供无外部依赖的校验脚本。24 项结构与裁剪检查通过。

所有样本故事都明确标为原创测试内容，不是原神剧情。真实正文与使用范围仍待确认，尚无网站、数据库、真实采集器或图谱 UI。

## 运行样本验证

使用 Python 3.10 或以上版本，无需安装第三方依赖：

```bash
python3 scripts/validate_sample.py
python3 scripts/validate_sample.py --query '先核对物资' --scope all
python3 scripts/validate_sample.py --view --scope opening
python3 scripts/validate_sample.py --view --scope all --purpose external_ai
```

第一条命令检查数据契约；后续命令演示保留不同出处的查询，以及按范围、用途和证据完整性裁剪图数据。它们不是生产搜索或权限接口，也没有调用外部 AI。

本机已有 `genshin-story-writer` 工作流文件，但尚未纳入本仓库、打包或连接真实检索工具。克隆仓库不能直接获得可用的创作系统；相关交付列入 T08。
