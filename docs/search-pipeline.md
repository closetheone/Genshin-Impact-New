# T05 服务端搜索与统一范围

日期：2026-10-12。状态：合成数据的服务端查询、分类 / 说话人筛选、签名分页与网页连接完成。仍不是生产搜索服务，真实数据准入和 M0 未通过。

## 1. 当前实现

```text
搜索页 → GET /api/search → SQLite 固定快照 + 当前用途 / 撤下策略
                                      ↓
                                  project()
                                      ↓
                可用范围统计 / 筛选项 → 查询 → 稳定排序 → 当前页

结果定位 → GET /api/view（同一快照、当前范围 / 用途）→ 阅读或图谱
```

`scripts/search_archive.py` 实现查询规则、排序和游标；`scripts/serve_prototype.py` 提供 HTTP 入口。搜索页不再先取得完整投影再自行搜索，浏览器里的 `searchPassages()` 已移除。

服务端先读取同一份快照和当前限制，再调用既有 `project()`；查询、计数、筛选项和分页均基于这一次投影，不另行读取未裁剪的原始内容。返回搜索页后，原文直达请求再次执行服务端边界；拥有段落 ID 不代表能够读取被撤下或范围外正文。

不新增依赖、数据库表、后台爬虫或 AI 调用。标准库本地服务、SQLite 存储与 v0.1 合成输入格式保持不变。

## 2. 匹配与分类

- **原句包含 `literal`**：统一 Unicode NFKC 和连续空白后，按连续子串匹配；不是全段等值，也不执行正则、SQL 通配符或模糊匹配。
- **关键词同时包含 `keywords`**：规范化后按空格拆词，要求每个词都在同一段落出现，词序可以不同；不会跨段拼接证据，不做中文自动分词或语义推断。
- 空查询或全空白查询表示浏览当前可用段落；与旧 CLI 的“空查询报错”规则不同。
- 查询不会改写原文。高亮只包裹原文中能精确找到的词；全角 / 空白规范化命中不一定能在原文中连续高亮，复制仍保留原字句。
- 分类来自允许读取的条目；当前 v0.1 样本只有 `quest`（任务文本），不摆出没有数据支撑的书籍、物品等分类。
- 说话人使用稳定 ID，两个“青禾”独立筛选；`narration` 表示没有说话人的叙述。范围内已无任何可用段落的说话人不进入筛选项。
- 分类 / 说话人数是当前范围和用途下、查询前的可用段落数；不会因输入查询而缩小。命中总数另在结果栏展示，避免两种计数混淆。

## 3. HTTP 参数

```text
GET /api/search?scope=opening&purpose=display&q=先核对物资
GET /api/search?scope=opening&mode=keywords&q=木匠%20木工&category=quest&limit=8
```

| 参数 | 默认与约束 |
| --- | --- |
| `scope` | 至少一个显式范围；可以重复参数传不同范围，不能重复值。仅接受样本定义的范围，不接受 `all` 简写 |
| `purpose` | 默认 `display`；支持 `display` / `export` / `external_ai` |
| `snapshot` | 首次可省略以读取活动快照；翻页必须显式使用首个响应的快照，非空且不能重复 |
| `q` | 默认空字符串；原始输入最多 200 个 Python Unicode 字符，匹配前进行 NFKC / 空白规范化 |
| `mode` | 默认 `literal`；可选 `keywords` |
| `category` | 默认 `all`；当前支持 `quest` |
| `speaker` | 默认 `all`；可用人物 ID 或 `narration`，最多 160 字符；不存在或当前不可用时返回零命中，不说明隐藏身份 |
| `limit` | 默认 8；1–50 的十进制整数；页面提供 8 / 16 / 32 三档 |
| `cursor` | 服务端响应的上一页 / 下一页游标；首次省略，传入时非空且最多 1024 字符 |

除多个不同 `scope` 外，参数均不能重复。未知参数、非法模式 / 分类 / 页大小等返回 400。请求 URL 上限 4096 字符、查询字段上限 16 个；不是任意长度的检索服务。

`/api/view` 不接受 `q`、筛选项或游标，避免一个参数在不同入口被静默忽略。

## 4. 响应与排序

| 字段 | 内容 |
| --- | --- |
| `dataset_kind`、`notice` | 原创合成标识和声明 |
| `snapshot_id`、`scope_ids`、`purpose`、`storage` | 本次实际快照、范围、用途和 `sqlite` 存储标识 |
| `query` | 规范化查询、匹配方式、分类、说话人和页大小，不包含游标密钥 |
| `results` | 当前页允许读取的段落，保留稳定 ID、原文、来源、快照、分支和裁剪后的后续连接 |
| `entries` | 当前页命中条目的可见元数据；无命中不返回推荐条目标题 |
| `characters` | 当前可用段落的说话人元数据，用于同名区分和筛选，不包含隐藏人物映射 |
| `stats` | 当前投影的可用段落、人物和有据关系数，不是查询命中数 |
| `facets` | 查询前的可用分类 / 说话人及段落计数 |
| `pagination` | `total`、`offset`、`limit`、`page`、`pages`、`next_cursor`、`previous_cursor` |

搜索响应没有完整 `passages` 或 `relationships` 数组。元数据和统计不等于全文一次性下发；后续仍需要正式大规模元数据限额。

排序沿可见 `next_ids` 做稳定拓扑排序，使用输入位置作为就绪节点间的确定性次序。`passage:31` 仍在 `23` 和 `24` 之间，重复对白按独立 ID 保留。循环连接导致 503，不按编号猜测顺序。空结果固定为第 1 / 1 页，无可用前后游标。

## 5. 固定分页与失效

游标是 HMAC-SHA256 签名的编码载荷，不是允许用户自由传入的偏移量。每次服务启动生成内存密钥，不写入仓库或 URL。签名用于约束分页参数，不是用户鉴权机制。

游标绑定规范化查询、模式、分类、说话人、页大小、快照、范围和用途，同时保存本次可见投影的摘要及分页偏移：

- 翻页须同时传回首个响应的快照，以及相同的查询和边界参数。不能拿开篇游标去读全部范围，也不能从导出用途换到阅读用途。
- 新快照被激活，不影响已固定旧快照的分页；不会把第二页悄悄切换到新版本。
- 同一快照叠加的新撤下或用途限制让可见投影变化时，返回 **409 `stale_cursor`**，不静默调整偏移、跳过记录或返回旧计数。
- 签名无效、参数不一致或服务重启后旧密钥失效时返回 **400**；游标仅在当前服务进程内有效，没有跨重启续用或持久化会话。
- 用户需主动从第一页重新检索，保留原查询与筛选，重新计算允许的结果和统计。读写并发时每次响应仍基于自己的完整读取事务，不声称能撤回已经发出的内容。

## 6. 页面与异常行为

- 提交、建议词、分类 / 说话人 / 匹配模式 / 页大小变化，以及范围 / 用途变化都会重新请求第一页。
- 只改输入框还没提交时，分页沿上次已提交查询继续，不将草稿拼进旧游标。
- 点击下一页 / 上一页由服务端游标读取；加载后把键盘焦点移到新结果区域，支持手机触屏操作。
- 请求开始即清空旧结果、取消旧请求，并用请求序号阻止迟到响应覆盖新范围。切到阅读 / 图谱也重新取投影，而不是错误复用搜索摘要。
- 失败显示重试；分页失效可“从第一页重新检索”。不退回全量 JSON 或全量 `/api/view` 做浏览器搜索。
- 页面 URL 继续固定快照；查询和游标仅留在当前页面会话中，尚未做完整搜索分享或浏览器刷新后恢复分页。
- 状态码延续本地服务规则：外部 Origin / 不可信 Host 为 403，未知快照为 404，存储损坏 / 无法排序为 503，POST 为 405，过长 URL 为 414。
