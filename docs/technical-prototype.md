# T03 技术方案与交互原型

日期：2026-10-12。状态：内部合成样本原型完成；不等于公开 V1、真实数据准入或 M0 通过。

## 1. 这次交付什么

- 文本检索：对当前可用段落做规范化字面匹配，相同对白的不同位置分别保留，可回到精确段落。
- 原文阅读：依据显式 `next_ids` 做稳定拓扑排序，展示分支、说话人、稳定标识、出处与可见后续连接；不按段落编号推测剧情。
- 人物关系图：从审核通过的明确关系生成一跳 / 二跳局部图，支持中心人物、关系类型、证据面板、等价列表、拖拽、平移和缩放。
- 引用与关系 JSON 导出：操作前重新请求导出用途的投影，检查快照和可用性；不把“网站可读”当成“可导出”。
- 响应式布局：桌面侧栏、手机底部导航；SVG 内文字使用实际画布尺寸，窄屏不整体缩成不可读的小图。

所有内容来自 `data/samples/story.json`，不是原神剧情。图里的“已审核”仅指合成记录的测试状态；`external_ai` 只是用途筛选，没有请求任何外部模型。

## 2. 当前技术决定

| 层次 | 本轮实现 | 选择理由与边界 |
| --- | --- | --- |
| 运行入口 | Python 3.10+ 标准库 HTTP 服务 | 无第三方运行依赖，仅绑定 `127.0.0.1`，不能作为生产服务 |
| 权威数据 | 仓库内的只读 JSON 样本 | 32 段足以验证交互；每次请求重新读取并校验，没有数据库、写接口或导入器 |
| 内容投影 | 复用 `validate_sample.project()` | 同一逻辑裁剪范围、来源用途、撤下记录、关系和完整证据组，不在前端另写一套准入判断 |
| 页面 | 原生 HTML / CSS / ES modules | 三页单入口 hash 路由，无构建过程、无外部字体或 CDN 资源 |
| 检索 | 投影后的段落在浏览器字面匹配 | 不是大规模全文索引、语义检索或正式分页搜索服务 |
| 阅读顺序 | 可见对话连接的稳定拓扑排序 | 分支分别标记；无可见后续不等于完整剧情结束；循环时报错 |
| 图计算 | 对投影后关系按类型筛选，再按无向邻接发现一跳 / 二跳 | 仅发现邻居时忽略方向，绘图和导出保留原始方向；不会从两跳推断直接认识 |
| 图呈现 | 原生 SVG + 关系列表 | 有向箭头、对称连线、平行分支曲线；图和列表指向同一证据 |

运行不需要 Node.js；本轮 Node / Playwright 仅用于开发检查。没有引入包管理器、框架或线上基础设施。

## 3. 文件与调用链

```text
web/index.html + styles.css
           ↓
web/app.js ──→ web/model.mjs（纯查询、排序与局部图函数）
           ↓ GET /api/view
scripts/serve_prototype.py
           ↓ validate() / project()
scripts/validate_sample.py ← data/samples/story.json
```

服务只开放固定前端资源和 `/api/view`，不把仓库根目录作为静态目录。`/.git/config`、原始 `/data/` 文件与路径穿越请求均不能读取文件。

## 4. 本地运行与路由

在仓库根目录运行：

```bash
python3 scripts/serve_prototype.py
```

浏览器打开 `http://127.0.0.1:4173`。端口占用时运行 `python3 scripts/serve_prototype.py --port 4174`，并使用对应端口；终端按 Ctrl+C 停止。

| 地址片段 | 行为 |
| --- | --- |
| `#/search` | 检索和浏览当前投影 |
| `#/read` | 阅读全部当前可见样本段落 |
| `#/read?passage=passage%3A03` | 精确定位；无效或受限标识显示不可用，不扩大范围 |
| `#/graph` | 默认以阿砚为中心 |
| `#/graph?center=person%3Astudent` | 指定中心人物；不可用时不猜测替代人物 |

路由不是正式的快照分享协议，没有携带全套筛选和布局。当前选择仅在本次页面会话中使用，没有实现账户设置或跨设备保存。

## 5. 原型读取接口

```text
GET /api/view?scope=opening&purpose=display
GET /api/view?scope=opening&scope=east&purpose=export
GET /api/view?scope=opening&scope=east&scope=west&scope=later&purpose=external_ai
```

- 必须至少提供一个显式 `scope`，不能重复；可用值为 `opening`、`east`、`west`、`later`。HTTP 接口不接受 CLI 的 `scope=all` 简写。
- `purpose` 可选，缺省为 `display`；可用值为 `display`、`export`、`external_ai`，不能重复。
- 未知参数、范围或用途返回 400；不可信 Host / Origin 返回 403；不存在的资源返回 404；POST 返回 405。
- 响应结构沿用 v0.1 投影：样本标识、声明、快照、范围、用途、条目、人物、段落和关系。
- 响应不会包含范围外正文、不可用人物、已撤下记录、无完整证据支持的关系或不可见的后续段落标识。
- 页面切换范围 / 用途立即清空旧视图，取消旧请求，并以请求序号阻止迟到响应覆盖新范围。出错只能重试，不回退到原始 JSON。

范围开关是用户主动选择的阅读边界，不是认证或授权系统。用途开关只演示样本策略；本地接口也不是 PRD 中完整的 AI 只读工具组。

## 6. 关系与导出细节

- 同名人物使用独立稳定 ID；选择器和证据面板明确列出 ID，图中短标签配合完整可访问名称，不合并两个“青禾”。
- 仅 `approved` + `explicit` 且有完整可用证据组的关系进入页面。组内段落须联合成立，不同组可以替代支持同一断言。
- `relation:parent` 在开篇缺少后续证据，因此不画线；全部样本范围下联合展示 `passage:08` 与 `passage:25`，并标注含后续证据。
- 东路对立与西路合作分别显示，不合并成一个无条件关系，也不声称同时发生。
- 局部图最多 50 人、100 条关系，超限明确标记截断；本轮未实现续取协议、自动排布质量保证或大图性能目标。
- 复制引用重新请求 `export` 投影，使用新投影的正文、说话人、出处和快照，不从旧页面直接复制。拒绝受限、撤下或跨快照内容。
- JSON 导出重新核验当前局部图的人物和关系；若任一关系已不可导出，整体拒绝并提示切换用途，不静默导出不完整的旧图。证据来自新投影中完整允许的组。
- JSON 包含合成声明、快照、范围、用途、中心、层级、类型、截断标记、人物、关系和证据；不导出隐藏节点或旧坐标。

## 7. 尚未实现与后续迁移

本轮没有真实来源导入、持久化数据库、生产部署、登录、真实游戏全文、正式搜索索引、素材清单、反馈受理、PNG 导出、完整图谱分享、AI 只读工具或 Skill 包。不得以原型通过代替这些验收。

T04 先沿用合成数据，建立持久化与导入到阅读的闭环：

1. 拟采用 SQLite 建立本地存储，先实现快照、稳定 ID、来源用途和撤下记录的事务约束；此处是下轮方案，不是已经存在的数据库。
2. 编写 JSON 导入器，先校验再提交，支持重复导入不增重复；非法输入整批失败，不留下半个快照。
3. 将当前直接读文件替换为存储读取，保留统一的范围 / 用途 / 证据投影逻辑。
4. 验证重启、重复导入、坏输入回滚和稳定段落定位。真实数据仍需先通过相应用途准入，来源待确认不阻止合成数据工程验证。

大规模搜索、生产 Web 服务、图布局库和正式 API 应依据真实规模重新验证；不把这次标准库服务直接暴露公网。
