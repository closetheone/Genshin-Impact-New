# T06 局部图、分享与导出

日期：2026-10-12。仅用于原创合成样本的本机工程验证，延续 SQLite、不可变快照及当前撤下 / 用途限制。不是生产鉴权或正式 AI 工具组。

## 1. 数据边界与读取

每次请求先 `load_snapshot` 在同一 SQLite 读事务中读取固定快照和当前限制，再 `project` 按范围、用途、审核与完整证据组裁剪。只有这份投影进入局部图计算、人物建议或关系详情。浏览器图页不再读取 `/api/view` 或计算全量邻接；阅读页仍使用该投影接口。

- `/api/graph`：中心、一跳 / 二跳、关系类型、情节条件及分页。
- `/api/relationship?id=...`：单条关系及所有当前完整可用证据组。拥有关系 ID 不会绕过范围检查。
- `/api/characters?q=...`：当前允许的人物姓名 / 稳定 ID 字面匹配；最多 20 个建议，更多时提示细化查询。不存在的姓名返回空集合；同名人物使用不同 ID。

通用参数 `scope` 必须明确且可重复但不重复取值；`purpose` 为 `display` / `export` / `external_ai`，默认 `display`；`snapshot` 省略时读取活动版本，界面首次响应后固定实际版本。未知参数、重复单值字段或非法值返回 400。缺失快照、人物或关系返回 404，不回退到其他快照。接口不返回隐藏记录的数量。

## 2. 图参数与条件含义

| 参数 | 默认 / 取值 |
| --- | --- |
| `center` | `person:student`；非空稳定 ID，至多 160 字符 |
| `hops` | `1`；只接受 `1` / `2` |
| `predicate` | `all` / `mentor_of` / `parent_of` / `opposes` / `cooperates_with` |
| `condition` | `all` / `opening` / `east` / `west` / `later` |
| `page` | `1`；正整数，至多五位；第二页起必须显式指定快照 |
| `cursor` | 可选签名续取令牌，必须显式指定快照；提供时以令牌页码为准 |

情节筛选匹配**关系记录的适用条件**：东路 / 西路要求相同 `branch_id`；后续要求关系自身的 `required_scope_ids` 包含 `later`；开篇公共要求无分支且仅依赖 `opening`。未标条件不会冒充东路 / 西路。某条开篇关系可能需要后续证据，证据面板会另标“含后续证据”；不把证据所在阶段改写成断言条件。

先筛类型和条件，再按无向邻接发现邻居，最后取到达节点间已有的关系；发现邻居不改变关系方向，也不生成推断边。中心不存在时报不可用；中心可用但无关系时保留单个中心节点。只有允许节点参与布局，同名人物在列表、选择器中显示稳定 ID。

## 3. 有界分页

按“端点最远跳数、关系 ID”稳定排序，顺序装入每页最多 50 人物 / 100 关系，每页保留中心与该页所有关系的两端。触及任一限额即开新页。各页关系不重复、不丢失；中心和跨页端点可以重复。二跳分页可能只包含某段路径的一部分，不能把分页解释为完整路径。

页面显示 `truncated`、当前页码、上一页 / 下一页和“重新读取第一页”。续取**替换**当前页，不在浏览器无限累积；列表、证据、PNG 与 JSON 对应同一页。总数只针对当前允许且匹配的子图。

签名游标使用与搜索相同的 HMAC 工具，但绑定独立的 `kind=graph`、中心、跳数、类型、条件、快照、范围和用途。可见投影变更返回 409；服务重启或令牌篡改返回 400。普通页码用于无令牌的分享重建，每次仍从当前权限重新计算；失效页返回 404。分享不是保留已撤下数据的凭证。

图响应只含当前页节点、关系、完整证据段落、相关条目、边界、查询、限额、分页和内容指纹。证据 `next_ids` 仅保留本次返回的段落；完整上下文通过固定快照阅读链接获取。

## 4. 分享与布局

URL hash 保存快照、中心、跳数、类型、条件、页码、图 / 列表模式，以及当前节点的归一化布局、缩放和平移。分享操作前重新请求当前用途的同一图，并比较内容指纹；证据或可见内容改变时要求重新读取。

链接不携带范围或用途授权，不修改接收者的顶部选择。新页面默认开篇 / 展示；提示可以手动调整。当前范围不足可能得到更小图、空关系或不可用提示。不可用版本不自动替换。

布局输入仅接受有限数值及合理区间，并与服务端本次返回的节点求交；图和列表两种模式下都过滤。发送分享和 JSON 前再次过滤。切换跳数尽量保留既有位置；改变中心或筛选重新布局。坐标不构成关系事实。

链接指向本机回环服务；没有公开托管、短链或跨设备同步。接收者必须能访问对应服务和快照。

## 5. 导出检查

JSON 和 PNG 共用重新核验流程：读取当前用途及 `export` 用途下的固定快照 / 同一页，比较包含节点、关系、证据全文与完整组、条目、查询和可见页数的 `content_revision`。任一内容不一致即拒绝，不静默删减旧图中的关系或证据。范围变化、路由切换、迟到请求不会覆盖新视图或完成旧下载。

- JSON：获准数据、证据出处、快照、范围、查询、截断标志和已过滤布局；不保存有进程生命周期的游标。
- PNG：图模式下从当前 SVG 和实际样式生成 1200×800 图像，附原创样本声明、快照、范围、当前页与截断信息、关系图例和方向说明。图像编码结束后再次核验，再触发下载。
- 列表模式可导出 JSON；PNG 按钮明确禁用，切回图模式即可导出。画布缩放和平移按当前视图保留。

检查确认的是最后一次服务器读取时的当前限制；本地下载文件无法在后续撤下时远程回收。没有实时推送撤下事件。
