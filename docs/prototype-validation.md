## 4. 手动复核步骤

```bash
python3 scripts/validate_sample.py
node --check web/app.js
node --check web/model.mjs
python3 scripts/serve_prototype.py
```

1. 打开 `http://127.0.0.1:4173`，确认“原创样本演示”及 17 段 / 2 关系，检索“先核对物资”。
2. 切换全部范围，确认检索得到两个独立出处；点第二项定位 `passage:21`，阅读中 `31` 位于 `23` 和 `24` 之间。
3. 打开关系图，点击亲属连线查看 `08` + `25` 联合证据和后续提示，检查东 / 西分支连线分别保留。
4. 全部范围、网站阅读用途下尝试关系 JSON 导出，应提示含不可导出关系。切换“素材导出”后，图中只保留 5 条关系并可下载 JSON。
5. 在阅读用途中复制 `passage:28` 应失败；复制允许段落应包含出处、快照和合成声明。剪贴板仍依赖浏览器实际权限，拒绝时页面须给出提示。
6. 缩小为手机尺寸，检查底部导航、内容范围、证据面板；也可切换关系列表完成同样的证据回链。
