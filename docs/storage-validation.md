## 2. 存储 / CLI：43 项

- 首次导入和自动激活；无损恢复与原始顺序；1 个快照 / 46 个记录身份 / 46 行记录 / 2 个来源策略；调整对象键顺序仍幂等。
- 同快照不同正文被拒；冲突后原数据完整；重复记录、悬空证据、未知撤下、真实数据标识、禁止存储和混合快照均拒绝；坏批次不增加记录，首次非法输入不创建数据库。
- 新快照默认不激活；可显式读取；再次导入并激活成功；旧段落正文仍保持原值；缺失快照不回退。
- 在写入段落之前注入真正的 SQLite 触发器失败，验证已写入的快照、身份与条目全部回滚，活动指针保持不变。
- 跨快照撤下生效，失去完整证据的师徒关系被删除；重新激活或重复导入旧快照不会恢复撤下内容。
- 来源导出用途变为待确认、AI 用途变为禁止后，旧快照同样受限，旧版重新激活不能放宽。
- 四路并发导入只形成一个批次；数据库完整性检查通过；只读打开缺失库失败且不创建文件。
- 不接管已有无关表的数据库，无关数据保留；存储正文被篡改后读取失败，幂等导入也不隐瞒损坏。
- JSON 重复键和非有限数字被拒；CLI 非法输入退出 1 并输出 JSON 错误；重复输入退出 0；独立新进程可读持久化快照。
- 补充检查跨快照变更稳定 ID 的记录类型被回滚，以及 SQLite 外键检查无违规。
