## 工程结果

- `skills/genshin-story-writer/` 是无凭据可移植包，包含 Skill、创作格式、检索契约、在线客户端和离线素材校验器。
- `scripts/serve_prototype.py --ai-scope opening` 启用固定最大范围的只读连接；默认服务不启用 AI 工具。六个工具均固定 `external_ai` 用途、快照和范围，并返回 `connection=live_readonly`。
- 在线客户端只接受显式回环 HTTP 地址，拒绝代理、重定向、凭据和超大请求 / 响应。离线校验器检查同一快照、范围、来源用途、段落链接、关系方向和完整证据组。
- Skill ZIP 使用固定白名单和稳定时间戳生成，安装到已存在目录会失败，不覆盖原文件。
