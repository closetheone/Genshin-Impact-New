- 一跳 / 二跳、类型、东路 / 西路 / 后续条件按定义筛选，未知条件不当作匹配。
- 中心不存在与孤立中心分别处理；导出用途移除内部资料，内容指纹能发现证据组丢失，即使关系 ID 未变。
- 额外 125 人物的星形图触发节点上限；18 人物稠密图触发关系上限。逐页遍历关系无重复、无遗漏，两端和中心齐全，普通页码重建相同内容。
- 游标绑定中心、跳数、类型、情节、范围、用途、快照和进程密钥；签名篡改、非法参数与重复字段拒绝；撤下使旧续页失效。

## 复核命令

```bash
python3 -m unittest discover -s scripts -p 'test_*.py' -v
python3 scripts/validate_sample.py
python3 -m py_compile scripts/*.py
node --check web/app.js
node --check web/model.mjs
python3 scripts/serve_prototype.py
```

打开图谱：默认开篇 3 人物 / 2 关系；全部范围、全部类型下为 4 人物 / 6 关系；切到素材导出用途为 4 人物 / 5 关系。东路 / 西路筛选分别核对各自关系；打开师徒边可查看联合组和独立组。

复制分享后在新页面打开，确认默认仍为开篇、快照固定、不能带出后续关系。素材导出用途下下载 JSON 和 PNG，检查图像声明、方向、图例及 JSON 完整证据。大图与撤下由自动化测试构造，禁止向日常默认库导入不可逆测试限制。
