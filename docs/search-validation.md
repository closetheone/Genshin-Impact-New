## 5. 基本复核

```bash
python3 scripts/validate_sample.py
python3 -m py_compile scripts/search_archive.py scripts/serve_prototype.py
node --check web/app.js
node --check web/model.mjs
python3 scripts/serve_prototype.py
```

1. 打开 `http://127.0.0.1:4173`：默认开篇 17 段，每页 8 条，共 3 页；切到全部样本为 32 段。
2. 检索“先核对物资。”：开篇 1 个、全部 2 个独立出处。第二个应定位 `passage:21`，URL 保留快照。
3. 输入“木匠 木工”：原句模式无命中；切换关键词模式命中 `passage:04`。筛选两个“青禾”时使用各自稳定 ID。
4. 切换到导出 / AI 用途，原始样本只剩 30 段、5 条可用关系；翻页后修改用途或筛选，应从第一页重新请求。
5. 在浏览器网络面板确认搜索只请求 `/api/search`，响应只含当前页 `results`；点击原文后才请求 `/api/view`。
6. 服务端重启后点击旧页面下一页，应该提示分页不可用；点击“从第一页重新检索”恢复，不能沿旧游标继续。

撤下和用途收紧没有恢复 UI，进一步演练请使用独立数据库，规则见 `storage-pipeline.md`。完整接口和游标规则见 `search-pipeline.md`。
