# 角色目录与资料接入

角色目录已接入本地原型的独立页面 `#/characters`，通过 `/api/characters?q=&limit=200` 读取当前快照中可见的人物记录。页面提供角色卡片、名称 / ID 搜索、资料状态筛选、稳定 ID、关系证据入口和后续资料字段的位置。

当前仓库只有原创合成样本，因此卡片中的立绘、元素、武器、阵营、稀有度和角色故事不会伪造或填入原神内容。没有这些字段时，页面显示“立绘待授权”和待接入说明。

真实角色批次接入时，建议先从少量角色开始，逐项记录：

- 名称、别名和稳定角色 ID；
- 来源页面、修订标识、游戏版本和内容类型；
- 基本信息字段与角色故事的具体授权范围；
- 立绘文件的来源、署名、展示 / 导出限制和撤下方式；
- 能回到原文的故事段落和关系证据。

角色目录的出现不代表真实资料已经获准。真实角色页面开放前仍需通过 `scripts/check_release_readiness.py`，并完成正文数据契约与来源核验。
