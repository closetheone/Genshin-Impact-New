## 备份、恢复与回滚

新增 `scripts/maintain_archive.py`：

- `verify` 使用 SQLite 完整性检查、外键检查、快照哈希、记录顺序、当前来源策略和撤下集合核验；也支持私有反馈收件箱的内容哈希核验。
- `backup` 使用 SQLite 在线备份 API，先在临时目录完成校验，再以不覆盖方式发布到新路径；拒绝已有文件、符号链接和残留 sidecar。
- `restore` 要求备份 SHA-256 和当前可信数据库，合并较新的撤下 / 用途限制；同一快照 ID 内容冲突、旧备份缺少受限身份或来源时停止，不恢复成更宽权限。恢复写入审计事件。
- `activate` 只切换活动快照，要求操作者给出期望当前版本和原因；限制集合不随回滚放宽，变更写入审计事件。

实际演练见 `evaluations/t09/recovery-drill.json`：备份、加入撤下和 external_ai 限制、回滚、恢复到新库、重启 HTTP 服务均成功；恢复后的 `passage:03`、`passage:31` 和师徒关系仍隐藏，`passage:04` 可读取。WAL 提交状态、私有反馈库、损坏库、错误哈希、半成品和故障导入也有自动化覆盖。

新增 16 项维护测试，连同既有 48 项共 64 项自动化检查通过；命令为 `python3 -m unittest discover -s scripts -p 'test_*.py'`。样本契约、Python 编译检查和 Git 差异空白检查通过。实际日常库和 4175 服务没有切换到测试数据。

## 十万段落本机基线

```bash

```

## 搜索扫描与排序专项优化（2026-10-13）

上一轮索引版搜索 P95 24.7118 秒仍未达标。本轮保留相同数据生成器、查询语义和边界，做了三项调整：

- 将当前允许的来源、条目、人物在 SQL 内预计算，省去每段相同的关联权限检查。
- 一次扫描同时产生命中数和说话人统计；无结果时跳过取页。
- 只排序有可见连接的节点，把它们与按原始位置索引读取的独立段落合并取页；确定当前页 ID 后才取正文，避免对十万个 ID 做 Python 堆排序、JSON 回传和全文载入。

单请求剖析中，旧路径约 0.98 秒、200445 次函数调用，其中全量 ID 排序约 0.35 秒；新路径约 0.19 秒、614 次调用，取页约 0.003 秒。基准 opening 范围有 99985 段，但只有 17 个节点参与连接排序。`EXPLAIN QUERY PLAN` 确认独立段落分页使用 `query_collection` 原始位置索引，不为 `ORDER BY` 建临时排序树。单请求剖析只用于定位，不替代以下端到端 HTTP 延迟。

```bash
python3 scripts/benchmark_archive.py --passages 100000 --concurrency 10 --requests 30 --output docs/evaluations/t09/benchmark-search-optimized-100k.json
```

| 场景 | 上轮索引版 P95 | 本轮 P50 | 本轮 P95 | 错误 |
| --- | ---: | ---: | ---: | ---: |
| 搜索 | 24.7118 s | 0.3783 s | 0.5097 s | 0 / 30 |
| 图谱 | 0.2212 s | 0.2298 s | 0.2788 s | 0 / 30 |
| AI 段落 | 0.0550 s | 0.0561 s | 0.0718 s | 0 / 30 |

搜索细分各 10 请求：高命中 P95 0.5197 秒、低命中 0.5053 秒、零命中 0.4775 秒；首次请求 0.0902 秒。基准现在同时核对准确命中总数和首页段落 ID 顺序，并保存每条样本的查询类型。并发幂等导入返回 `unchanged`，同时查询约 0.6031 秒。详见 [`benchmark-search-optimized-100k.json`](evaluations/t09/benchmark-search-optimized-100k.json)。

新增三项差分回归后，共 77 项 Python 测试通过。固定种子的随机 DAG 混合逆序边、汇合、独立段落、隐藏前驱和撤下，逐页对照原始完整投影算法，检查排序无重复或缺失；另覆盖 Unicode / 全角 / 空白 / 字面符号 / 大小写 / 关键词 AND / 说话人筛选，以及撤下后的游标失效、统计和筛选数量。编译、样本校验、前端语法和差异检查通过。

搜索与图谱通过这一次本机合成基准的 P95 ≤1 秒目标。测试文本短、绝大部分段落独立，不代表真实长文本或密集连接的性能；字面匹配仍扫描索引，深页仍有 OFFSET 成本，该次测量时尚未建立 FTS 或跨请求结果缓存；后续缓存复测见下文。真实来源准入、真实剧情和公开 V1 仍未完成。
